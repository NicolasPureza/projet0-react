# Projeto 01 — TechStore (React)

Aplicação web responsiva de catálogo e loja de tecnologia desenvolvida com **React 18** e **Vite** para a atividade prática do **SENAI**.

## 🚀 Recursos Utilizados do React
- **Componentização**: `Header`, `CategoryFilter`, `ProductCard` e `CartModal`.
- **Hooks (`useState` e `useMemo`)**: Gerenciamento de estado reativo do carrinho, favoritos, busca textual e filtragem otimizada por categoria.
- **Props e Callbacks**: Comunicação unidirecional entre componente pai (`App`) e componentes filhos.
- **Renderização Condicional e Listas**: Uso de `.map()` com `key` e operadores ternários.

## 📦 Como executar
```bash
npm install
npm run dev
```
